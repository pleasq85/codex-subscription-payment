## 额度是怎么算的：两个上限同时生效

这是选套餐之前最该搞懂的部分。Codex 的额度不是一个数字，而是两个上限叠加：一个是几小时滚动的短期窗口（常见的拆解说法叫“5小时额度”），另一个是周额度。你周二全程没碰到小时上限，周五也可能因为周额度耗尽被卡住。只盯着一个数字做计划，很容易翻车。

第二个变量是模型档位。同一个任务，用 Luna 或 Terra 跑，消耗的额度只是 Sol 的零头。日常琐事交给快档，省下来的额度留给真正难的活。

具体数字这里不写死——今年额度调过好几轮，最近一次在8月初，现在写下来的数字下个月可能就不对了。更靠谱的判断方式：先用免费版跑两周真实任务，数一数撞了几次上限，再决定要不要付费、付到哪一档。预防性升级是最贵的答案。

## 国内直接订阅，为什么会失败

很多人以为“能打开 ChatGPT 就能付款”，实际不是。卡点集中在三个层面：

**支付网关的风控。** OpenAI 用 Stripe 处理订阅扣款，Stripe 对节点 IP 有很强的风险评估。用的是公共机房 IP，或者大量用户共用的“脏”节点，卡完全正常也会被 403 拦截或直接拒付。

**发卡行的地域拦截。** 国内所有银行发行的外币卡、全币种卡——Visa、万事达、American Express 都一样——会被 Stripe 通过卡片 BIN 段识别出大陆发卡行，然后直接拒绝。招行全币种、中信 i 白金、各家 JCB 都有人试过，结论一致，不用再浪费时间。

**3D Secure 二次验证失败。** 部分虚拟卡绑卡时需要短信或 App 二次验证，时差、通道延迟或平台故障都会导致验证超时。卡片本身不兼容的话，多刷新几次没有意义。

还有一类提示是 "Country not supported"：网络出口必须落在 OpenAI 支持订阅的地区，比如美国、英国、新加坡、日本或加拿大。聊天页面打得开，不代表支付页会放行。

### 路线一：海外虚拟信用卡

原理是在海外平台申请一张虚拟借记卡或信用卡，用 USDT 或跨境支付通道充值，再绑定 ChatGPT 完成订阅。听起来直接，门槛其实最高：开卡要实名认证，充值绕不开加密货币，还得配一段干净的住宅级网络环境，节点欺诈分一高照样被拒。它的优点是一卡多用，之后绑其他海外 AI 服务也用得上。

更大的问题是稳定性。2025年下半年起，一批常用的虚拟卡平台因为跨境支付合规问题陆续停止服务，域名失效，卡里的余额能不能追回很难说。手上还有老平台的卡，尽快翻出订单记录去申诉；网上“老平台复活”“内部通道”这类消息基本别信，钓鱼的居多。

## 充值失败先看这里：常见报错排查

报错之后第一件事不是反复点支付——风控分会越叠越高，订阅没开成，账号先进了观察名单。对照排查：

- **Your credit card was declined**：国内 BIN 段被拒，没有可行的绕过方案，换路线。
- **Country not supported**：检查网络出口是否在支持地区，保持节点稳定，别几分钟换一个国家。
- Stripe 支付页无限加载或白屏：换更稳的网络，用无痕模式清缓存重试；连续失败三次以上先停手。
- **Something went wrong, please try again later**：短期多次提交或虚拟卡 BIN 被重点关注时出现，冷却 24 到 48 小时再试。
- 礼品卡提示已兑换：卡有问题，停用，换正规渠道。
- 付了钱没到账：先退出账号重新登录，确认付款用的是哪个邮箱（多账号的人经常充到小号），再到 Settings → Plan 看订阅状态；一小时后还没变化，去邮箱搜 "Receipt from OpenAI" 确认扣款记录。
- 账号被停用：充值前好好的、充值后立刻被封，重点怀疑支付来源——黑卡、共享号、密码外泄都会触发。账号永久封禁时，聊天记录和历史数据基本一起消失。
